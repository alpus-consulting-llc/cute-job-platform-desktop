# Cute Job Platform for Windows

Installers for the Cute Job Platform desktop app by Alpus Consulting LLC.
This repository holds **releases only** — no source code.

**Download:** [CuteJobPlatform-Setup.exe](https://github.com/alpus-consulting-llc/cute-job-platform-desktop/releases/latest/download/CuteJobPlatform-Setup.exe)
(or from https://www.cutejobplatform.space/download).

- Windows 10 or 11, 64-bit. Installs for the current user; no administrator needed.
- If Windows shows "Windows protected your PC", click **More info → Run anyway**
  (the installer isn't code-signed yet).
- Installed apps update themselves automatically from the releases here.
